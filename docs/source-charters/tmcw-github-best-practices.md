## GES interpretation: authority and limits

Use the source as contextual collaboration and change-management advice, retaining
the intended product lifecycle. It is author opinion, not GitHub platform authority
or an automatically applicable universal standard.

Explicitly unopinionated choices—including some branch and merge practices—must
remain distinguishable from recommendations. GES must not attribute its own
naming, deletion or merge-method requirements to this source when the source
does not choose them.

## Synthesis obligations

Record rationale and applicability when generalizing beyond the original context.
Separate retained advice from strengthened local obligations and preserve any
deliberately unspecified choice for owner decision.
