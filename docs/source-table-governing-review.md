## Provider interpretation

The provider matrices preserve literal source fields. `isPublic` is labelled **Partner** in the pinned UI; `isPrivateWithGhas` is **User alert**. A public/private-support phrase in existing extracted statements names a literal key and must not be treated as effective repository coverage. Partner notifications and repository user alerts are separate mechanisms. The older subject README has conflicting field/renderer descriptions; the pinned TSX page, component and middleware determine this matrix interpretation.

Validity and metadata fields can contain Liquid. The middleware evaluates those expressions in request context; this batch preserves them without claiming effective target booleans. Optional field absence remains distinct from explicit false even though UI truthiness can show both as No. `isduplicate` produces a token-version caveat link, so duplicate markers and their row occurrences stay in evidence.

Pattern category, product, plan and version caveats remain attached: generic patterns lack validity checks; passwords lack push protection and validity checks; specific GHES rows and metadata/validity features have separate version gates. Provider push protection targets recent confidently identified token versions, not every legacy token.

## CodeQL interpretation

Default and Extended describe suite membership. Extended includes Default and adds lower-precision/severity queries, with increased false-positive potential. Autofix is per-query support, not an executed or guaranteed fix. Equal query display names retain their distinct help identities and language context.

The tables describe a latest-release snapshot; an initial GHES bundle can lack listed queries. The pinned Autofix feature gate includes FPT/GHEC and excludes GHES, while raw table rows retain Autofix column cells. Effective installed versions, feature entitlement and execution are unmeasured.

The ten language wrappers retain their own table, suite and version dependencies. Security tables omit metadata/metrics queries without CWE tags; code-quality tables are a separate pipeline. None of the generator, CodeQL CLI or private package was executed.
