## Existing work and accounting

**3,424 authored text claims across 217 source paths**. The 65 substantive documents
contain **2,992 of those claims**. Routing reduces the primary document queue by
73.4%, while retaining 87.4% of the existing text claims in that queue. This is a
file-role reduction, not a claim that the remaining synthesis takes 73.4% less time.
Asset observations are separate and are not included in these text-claim counts.

These are existing source-review records, not newly performed or independently
certified reviews. Their reference-only dispositions do not establish completed
semantic consolidation. This routing adds **zero new artifact reviews, zero new
claim reviews, zero reconciled claims and zero adopted controls**. No whole-source
gate is closed by assigning file roles. The original inventory denominator stays
244 and the six-source inventory stays 13,657.
