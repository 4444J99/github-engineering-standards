# ADR 0001 — Repository identity

Decision: `github-engineering-standards`.
Status: user approved, October 1, 2026.

The name identifies the platform and the enduring responsibility: reusable engineering standards. It does not encode source count, temporary consolidation work, maturity, version, implementation language or account hierarchy. The previous working title “GitHub Systems Standard” remains in the historical implementation contract.

Future platform-neutral concepts may be shared through versioned interfaces. This decision does not authorize renaming the repository or splitting it into arbitrary components.
